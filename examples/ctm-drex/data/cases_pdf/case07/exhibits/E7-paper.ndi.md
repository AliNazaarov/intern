# # Low-Latency Pronunciation Scoring for Mobile Learners

**Rafael Quintero-Sato** (Parlo Learning)

*Workshop on Speech Technology in Education, 2022*

**Abstract.** We describe a phone-level pronunciation scoring system designed to run on mid-range mobile devices. The system aligns learner speech to a native-speaker acoustic model and scores each phone with a calibrated confidence. On a test set of 4,000 utterances, scores agree with expert raters at a correlation of 0.81. Median scoring latency on device is **180 milliseconds**, with 95th-percentage latency of 410 milliseconds.
